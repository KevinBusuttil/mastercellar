# Master Cellar ERPNext portal

A **Frappe / ERPNext v16** custom app for a demonstration storefront at
`mastercellar.kodetrek.com`.

The application is intentionally isolated from the main Cassar Camilleri and
other production sites, and it will not install a new commerce/payment engine.

Development is tracked in a feature branch until the initial demo is reviewed.
Do not deploy to the shared Frappe bench until the branch is reviewed.

See the forthcoming deployment and demo instructions in this README after the
initial feature branch is merged.
